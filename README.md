# ✈️ Flight Status Tracker

A simple web application to **search flights, view details, and trace routes on a live map**.  
Built with **HTML, CSS, JavaScript, and Leaflet.js (OpenStreetMap)** — no API keys required.

---

## 🚀 Features
- **Search Flights**: Enter a flight number to view airline, status, departure, and arrival details.
- **Live Map**: Displays departure and arrival airports with markers, zooms to fit the route.
- **Flight Listings**: Dedicated `flights.html` page showing available flights in a clean table format.
- **Contact Page**: Separate `contact.html` with example email, phone, and address.
- **Responsive Design**: Background image with overlay for readability, styled navigation menu.

---

## 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Map Integration**: Leaflet.js + OpenStreetMap tiles
- **IDE**: Visual Studio Code
- **Version Control**: Git + GitHub
